# Davinvic thinggy

Davinci thinggy is a macro pad so that i can edit videos in davinci better, btw i copyed the example project as a base for this one. 
## Features:
- EC11 Rotary encoder for davinci scrollling
- 4 Keys

## Firmware Overview
This hackpad uses [QMK](https://qmk.fm/) firmware for everything. 

- the rotary encoder should do scrolling, pressing does nothing ig
- The 4 keys currently act as macros I dynamically change in VIA.

## BOM:
Here should be everything you need to make this hackpad

- 4x Cherry MX Switches
- 4x DSA Keycaps
- 5x M3x5x4 Heatset inserts
- 5x M3 SHCS Bolts
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
- 1x Case
